## ⚙️ 技术说明（质量基线）

所有特效都遵循同一套工程标准，确保**好看又不卡**：

- **零依赖、单文件、可离线**：不引用任何 CDN / 外链字体 / 外部图片，复制即走。
- **循环内零 `shadowBlur`**：发光一律用 `globalCompositeOperation = 'lighter'` 叠加实现，避免逐帧 `shadowBlur` 导致的卡死（早期版本曾因此黑屏/掉帧）。
- **错误兜底**：每个文件顶部注入 `window.onerror`，运行时出错会显示红色提示而非直接黑屏。
- **响应式适配**：监听 `resize` 并按设备像素比（DPR）缩放，手机电脑都清晰。
- **已验证**：每个文件均用 Node `vm` + Canvas/DOM 桩模拟运行多帧，确认无运行时报错、无 `NaN` 坐标。

## 🎨 自定义（改名字 / 文案 / 配色）

- **改名字**：`qixi-10-name-heart.html` 与 `qixi-13-love-rain.html` 支持输入文字，粒子会组成你写的内容。
- **改心里话**：
  - `qixi-20-draw-heart.html` → 修改脚本顶部 `MSG_LINE1` / `MSG_LINE2` 常量。
  - `qixi-27-love-letter-card.html` → 直接改 HTML 里的卡片文案。
  - `qixi-29-love-you-text.html` → 修改文字采样目标字符串。
- **改配色 / 节奏**：各文件颜色多为顶部 `CONFIG` 对象或 HSL 常量，直接改数值即可（粉色系 / 彩虹系 / 霓虹系各有风格）。

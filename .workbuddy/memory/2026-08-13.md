## 黑屏排查 & 全局错误捕获（重要）
- **现象**：qixi-13 打开即全黑、啥都不显示 → 不是卡，是 JS 运行时报错导致整页静默停摆。
- **根因**：`resize()` 在脚本第 26 行被立即调用，但它内部 `initRain()/generateHeart()` 用到的 `let rain`、`let heartParticles` 还没声明 → `Cannot access ... before initialization`（let 的 TDZ）。修复：把初始化 `resize()` 从顶部挪到所有 `let` 声明之后（脚本末尾、紧接 `requestAnimationFrame` 之前）。
- **排查手法**：用 node+vm+手写 canvas/DOM 桩「真跑」每个文件前几帧，可抓到 `new Function` 语法检查抓不到的运行时错误（TDZ、未定义 API 等）。桩需补全 setInterval/setTimeout/performance/window 及带 addEventListener/remove/getContext 的 DOM 元素桩，否则易误报。
- **全局加固**：给全部 13 个 qixi-*.html 注入 `window.onerror` 错误捕获层（`<body>` 后插一段 `<script>`），任何运行时错误会在页面顶部红字显示，而非静默黑屏，便于用户截图报错。注入幂等。
- **经验**：canvas 特效若首屏即调 `resize()/init()`，务必确保它在所有 `let/const` 声明之后执行，避免 TDZ 黑屏。
